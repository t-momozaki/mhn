# Package index

## Distribution functions

Density, distribution, quantile and random generation, following the
argument conventions of base R’s stats package. All four are vectorised
over the evaluation argument and over the parameters, with the usual
recycling rule.

- [`dmhn()`](https://t-momozaki.github.io/mhn/reference/dmhn.md) :
  Density of the Modified Half-Normal Distribution
- [`pmhn()`](https://t-momozaki.github.io/mhn/reference/pmhn.md) :
  Distribution Function of the Modified Half-Normal Distribution
- [`qmhn()`](https://t-momozaki.github.io/mhn/reference/qmhn.md) :
  Quantile Function of the Modified Half-Normal Distribution
- [`rmhn()`](https://t-momozaki.github.io/mhn/reference/rmhn.md) :
  Random Generation from the Modified Half-Normal Distribution

## Summary statistics

Closed-form summaries of a single MHN(alpha, beta, gamma) law. These
take one parameter triple rather than recycling vectors.

- [`mhn_mean()`](https://t-momozaki.github.io/mhn/reference/mhn_mean.md)
  : Mean of the Modified Half-Normal Distribution
- [`mhn_var()`](https://t-momozaki.github.io/mhn/reference/mhn_var.md) :
  Variance of the Modified Half-Normal Distribution
- [`mhn_skewness()`](https://t-momozaki.github.io/mhn/reference/mhn_skewness.md)
  : Skewness of the Modified Half-Normal Distribution
- [`mhn_kurtosis()`](https://t-momozaki.github.io/mhn/reference/mhn_kurtosis.md)
  : Excess Kurtosis of the Modified Half-Normal Distribution
- [`mhn_mode()`](https://t-momozaki.github.io/mhn/reference/mhn_mode.md)
  : Mode of the Modified Half-Normal Distribution
